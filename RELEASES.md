# Releases

KOS2 release notes live in [`CHANGELOG.md`](CHANGELOG.md).

KOS2 uses the `YY.MM.X` versioning scheme:

- `YY` — last two digits of the year (e.g. `26` for 2026)
- `MM` — month number, no leading zero (e.g. `4` for April)
- `X` — release counter for that month, starting at `1`

Example: `26.4.8` is the eighth release shipped in April 2026.

The first KOS2 release on this scheme was `26.4.1`. Everything before that comes from the upstream `obsidian-copilot` history and is preserved in [`docs/release/upstream-archive.md`](docs/release/upstream-archive.md).

# Agent Claims

Agents use this directory to declare active work areas and avoid conflicting edits.

Before editing the repo, create one claim file named:

```text
<agent>-<scope>.md
```

Use the policy in [`docs/agent-collaboration.md`](../agent-collaboration.md).

Current convention:

- `codex-*` files are Codex claims.
- `claude-*` files are Claude Code claims.
- Keep each claim scoped to one workstream.
